详细描述

定义了仿真系统中的基础节点类

Node类是仿真系统中的核心组件，它实现了以下功能：

  • 支持Tick-Tock仿真机制
  • 管理节点的持久状态和临时状态
  • 提供数据包的生成和管理功能
  • 支持输入/输出端口系统
  • 实现子节点的树形结构
  • 提供序列化和反序列化功能
  • 支持多种仿真模式（最快模式、单步模式、跟踪模式）
  • 支持并行化处理（线程池）
