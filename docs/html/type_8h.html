详细描述

定义了仿真系统中的基础类型系统

该文件定义了以下内容：

  • 基础ID类型（NodeID、PacketID、PayloadID、TypeID）
  • 序列化方法枚举
  • 并行化方法枚举
  • 模拟模式枚举
  • 类型注册系统

特性：

  • 提供类型安全的ID生成和管理
  • 支持运行时类型注册和查询
  • 实现了类型名称到ID的映射
  • 提供了类型注册的宏支持
