# 生产者-消费者网络测试

本测试用例创建一个生产者-消费者网络，并使用node-editor GUI查看每一拍的状态变化。

## 功能

- 启动一个服务器线程，创建一个生产者-消费者网络
- 连接到服务器并可视化显示网络
- 单步执行模拟，观察网络状态变化
- 连续执行模拟，观察网络动态变化
- 重置模拟，返回初始状态

## 使用方法

### 编译和运行

```bash
# 给脚本添加执行权限（只需执行一次）
chmod +x run_producer_consumer_test.sh

# 运行测试
./run_producer_consumer_test.sh
```

### 命令行参数

- `--no-visual` 或 `-n`: 禁用可视化（仅运行测试逻辑）
- `--mock-ui` 或 `-m`: 使用模拟UI（适用于无图形环境）

例如：

```bash
./run_producer_consumer_test.sh --no-visual
./run_producer_consumer_test.sh --mock-ui
```

## 操作说明

测试程序会自动执行以下步骤：

1. 启动服务器并创建生产者-消费者网络
2. 连接到服务器并显示初始网络状态
3. 执行5次单步模拟，每次执行后暂停一段时间以便观察
4. 启动自动模拟，连续运行一段时间
5. 停止模拟并重置到初始状态
6. 完成测试

## 自定义

如需修改测试行为，可以编辑 `producer_consumer_test.cpp` 文件：

- 修改单步执行的次数（默认5次）
- 调整显示时间长度
- 添加更多操作和检查

## 排障

如果遇到问题：

1. 确保sim库已经编译并安装
2. 检查服务器端口是否被占用（默认8080）
3. 如果GUI无法正常显示，尝试使用 `--mock-ui` 参数
