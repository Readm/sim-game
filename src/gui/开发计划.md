### 1. 节点系统映射

将仿真系统的节点概念映射到可视化节点：

```cpp
// 可视化节点结构
struct VisualNode {
    ed::NodeId id;
    std::string name;
    ImColor color;
    std::vector<VisualPin> inputs;
    std::vector<VisualPin> outputs;
    ImVec2 position;
    ImVec2 size;
};

// 可视化引脚结构
struct VisualPin {
    ed::PinId id;
    std::string name;
    TypeID type_id;  // 使用仿真系统的TypeID
    PinKind kind;    // Input/Output
    ImColor color;
};
```

## 前后端分离架构设计 🔄

### 总体架构

```
+----------------+      HTTP/WebSocket     +----------------+
|                |<----------------------->|                |
|  前端 (GUI)     |                        |  后端 (服务器)   |
|                |                        |                |
+----------------+                        +----------------+
| - NetworkViewer|                        | - 模拟引擎       |
| - ImGui界面     |                        | - 网络状态管理   |
| - HTTP客户端    |                        | - REST API     |
| - WebSocket客户端|                        | - WebSocket服务|
+----------------+                        +----------------+
```

### 接口设计

#### REST API
- `GET /api/status` - 获取服务器状态
- `GET /api/network/state` - 获取当前网络状态
- `POST /api/simulation/start` - 启动模拟
- `POST /api/simulation/stop` - 停止模拟
- `POST /api/simulation/step` - 单步模拟
- `POST /api/simulation/reset` - 重置模拟
- `PUT /api/network/nodes/:id` - 更新节点属性
- `POST /api/network/connections` - 创建连接
- `DELETE /api/network/connections/:id` - 删除连接

#### WebSocket 事件
- `state_update` - 网络状态实时更新
- `simulation_status` - 模拟状态更新
- `error` - 错误通知

### 已实现组件
